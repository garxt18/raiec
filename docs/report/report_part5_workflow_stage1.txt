RAIEC INTERNSHIP PROJECT REPORT - PART 5: WORKFLOW STAGE 1

STAGE 1: PDF UPLOAD & INGESTION

FRONTEND (step1-upload.html):
- Drag-and-drop or file picker
- Validate: PDF type, size < 30MB
- FormData with file
- POST to /api/tenders/upload

BACKEND (TenderService.ingestPdf):
1. Check duplicate by tender number
2. Extract text with Apache PDFBox
3. Parse structure with TenderPdfParser:
   - NIT header (tender no, date, dept, amount)
   - Identify schedules (A/B/C/D)
   - Parse line items (serial, description, qty, unit, rate, amount)
   - Detect rate breakups (material/labor/equipment)
   - Classify: SCHEDULED or NON_SCHEDULED
4. Extract NS items, generate LAR codes (NS001, NS002...)
5. Save to database with cascades
6. Set status = UPLOADED
7. Return tender ID

RESPONSE:
- Store tender ID in sessionStorage
- Navigate to step2-ocr-extract.html

TECHNOLOGIES:
Apache PDFBox, Regex patterns, Spring Data JPA, FormData API, Fetch API
