How this analysis is produced

1

Deterministic checks

The four problem-statement checks above are rules, not predictions. Each one recomputes from the extracted figures, so the same estimate always produces the same verdict and every flag can be traced to a specific line item.

2

Rate references

Scheduled items are matched to CPWD DSR and IRUSSOR by item code, falling back to description similarity when a code is absent. Non-Scheduled items have no published rate, so they are compared against the lowest rate the railway has previously accepted for the same work.

3

The written assessment

The summary at the top is phrased by a language model from the figures already computed below — it interprets, it does not calculate. When no model is configured the same facts are written up by a built-in rule-based narrator, and the label above the summary always states which produced it.

4

Advisory, not deciding

Nothing here approves or rejects anything. Every flag is a prompt for the reviewing officer to look closer; the decision, and the responsibility for it, remain entirely theirs.
