# Images

Drop the North Western Railway photograph here as:

    images/nwr-headquarters.jpg

It is shown in the "North Western Railway" section at the bottom of the home page.
A landscape image works best (roughly 3:2 or 16:9, at least 1200px wide).

If the file is absent the section still renders correctly — the photo area simply
hides itself, so a missing image never leaves a broken-image icon on the page.

Other formats work too; if you use .png or .webp, update the <img src> in
index.html to match.
