How it works

From tender PDF to
a defensible verdict.

RAIEC reads a construction tender estimate, structures every line item, checks each rate against the official schedules and past accepted rates, and hands an officer a clear, evidence-backed decision — and every approval makes the next check smarter.

The estimate-checking pipeline

Six stages turn a raw PDF into a reviewed decision. Follow the line.

PDF ingestion

1 · Upload the estimate

Drop the IREPS tender PDF (native or scanned). RAIEC records the NIT header — tender number, name of work, zone, advertised value and closing date.

1
Structured parsing

2 · Extract & structure

Schedules (A / B / C / D), their line items, rate breakups and Non-Scheduled (NS) items are parsed automatically into clean, queryable data — no manual typing.

2
Code + fuzzy match

3 · Rate matching

Each item is matched to its reference: CPWD DSR & IRUSSOR by item code, with a fuzzy description fallback; NS items are matched against the LAR dataset of previously accepted rates.

3
Directional thresholds

4 · Variance & verdict

Quoted rate vs reference, judged by direction: at or below the reference is fine (cheaper is good). Only over-quoting is flagged — OK, WARN (5–10% over) or FAIL (>10% over).

4
Automated checks

5 · AI analysis

Rule-based problem-statement checks run over the whole estimate: rate deviation, missing references, math verification and duplicate-proposal detection — each summarised with the items that triggered it.

5
Human-in-the-loop

6 · Officer review

An officer sees the full picture and approves or rejects. On approval, the estimate's accepted Non-Scheduled rates flow into the LAR dataset — keeping the lowest rate per item.

6

Inside the matching engine

Maximum accuracy comes from trying the most precise match first, then falling back intelligently.

1

Exact item code

DSR / IRUSSOR items are matched by their published code (e.g. 4.1.4) for the right edition — the most reliable link.

2

Fuzzy description

If the code isn't found, a trigram-similarity search finds the closest description in the book and shows a confidence %.

3

LAR for NS items

Non-Scheduled items have no rate book, so they're matched against the Last Accepted Rate dataset — excluding the tender's own past records.

✓

Verdict

The matched reference drives the directional variance and the OK / WARN / FAIL status the officer reviews.

OK — at or below reference (≤5% over)
WARN — 5–10% over
FAIL — more than 10% over

It gets smarter with every approval

Each approved tender adds its Non-Scheduled rates to the LAR dataset. The next estimate is checked against a richer, real history of accepted rates — so coverage and accuracy compound over time.
